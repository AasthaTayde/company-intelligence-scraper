# Before submission

1. Run `npm install`.
2. Run `npm test` and fix any environment-related issues.
3. Run a real scrape against a website you are permitted to access.
4. Inspect the generated CSV/JSON and logs.
5. Replace any sample output with output generated by your own run.
6. Add meaningful Git commits and push to your own GitHub repository.
7. Invite the assignment's specified reviewer email from GitHub repository settings.

This starter project intentionally focuses on supplied seed URLs. Query-to-company discovery requires a search provider and should be implemented using a legitimate API/source if it is required for your chosen scope.
